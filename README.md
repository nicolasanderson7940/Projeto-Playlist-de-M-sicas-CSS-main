# 🎵 Projeto Playlist de Músicas

Um projeto web que apresenta uma interface musical com perfis personalizados, capas de álbuns e arquivos de áudio.

## 📋 Sobre o Projeto

O **Projeto Playlist de Músicas** foi desenvolvido para praticar a criação de páginas web com HTML e CSS, utilizando uma interface inspirada em plataformas de streaming musical.

A página inicial permite selecionar um perfil entre os usuários apresentados. Cada perfil possui uma página própria, reunindo elementos visuais relacionados à experiência musical.

## 🚀 Funcionalidades

* Seleção de perfis de usuários.
* Páginas individuais para cada perfil.
* Organização visual de capas de músicas.
* Utilização de imagens e arquivos de áudio.
* Navegação entre páginas por meio de links.
* Interface estilizada com CSS.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** estrutura das páginas e navegação.
* **CSS3:** estilização e organização dos elementos.
* **Imagens e áudios:** recursos utilizados na interface musical.

## ▶️ Como Executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo `index.html` no navegador.
3. Se preferir, utilize a extensão Live Server.
4. Selecione um perfil para acessar sua página.

É importante manter as pastas de imagens e áudios nos locais esperados pelo código para que os arquivos sejam encontrados corretamente.

## 🎯 Objetivo de Aprendizado

Praticar HTML e CSS, trabalhar com arquivos multimídia e desenvolver a navegação entre diferentes páginas de um mesmo site.
